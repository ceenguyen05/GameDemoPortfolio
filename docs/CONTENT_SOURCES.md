# Game descriptions

Updated November 11, 2026. Upcoming games use concept descriptions, not claims that the reference games' features already exist in these builds.

- **Multi Player Obby:** Casey confirmed the name, browser-first direction, cooperative play, and 2–6 players. [Teamwork Puzzles Obby by Flux Games](https://www.roblox.com/games/12820501582/Teamwork-Puzzles-Obby) describes shared puzzles and obstacle courses. Copy uses that general teamwork loop without inventing maps, mechanics, release dates, or controls.
- **Moon Sweeper:** Casey identified the viral Steam/Roblox moon-cleaning games as the reference. [Moon Sweepers by DragDrop Games on Steam](https://store.steampowered.com/app/5335510/Moon_Sweepers/) describes collecting lunar dust and upgrading tools. [Sweep The Moon on Roblox](https://www.roblox.com/games/109576450376407/Sweep-The-Moon) identifies Moon Sweepers as its inspiration. The project copy describes a planned cleaning loop; it does not promise the original's 16-player multiplayer, vehicles, or automation.
- **Devil 2:** Casey confirmed this exact display title, a browser remake, and Trea Edwards as creator. Trea supplied the playable demo at <https://test-lemon-pi-19.vercel.app/> on November 11, 2026. The entry is live and links to that demo. Copy stays general without importing Level Devil's mechanics or claiming an official association.

Multi Player Obby and Moon Sweeper use Coming soon and have no launch URL. All three use Web browser, with no confirmed release date, controls, or changelog. Their covers are original illustrations, drawn as SVG in `art/covers/` and rendered to WebP with `npm run render:covers`. They are labeled concept artwork and are not gameplay screenshots. Existing route slugs are retained so previously shared URLs still work.
