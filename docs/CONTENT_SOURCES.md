# Upcoming game descriptions

Updated November 10, 2026. These are concept descriptions for unreleased browser projects, not claims that the reference games' features already exist in these builds.

- **Multi Player Obby:** Casey confirmed the name, browser-first direction, cooperative play, and 2–6 players. [Teamwork Puzzles Obby by Flux Games](https://www.roblox.com/games/12820501582/Teamwork-Puzzles-Obby) describes shared puzzles and obstacle courses. Copy uses that general teamwork loop without inventing maps, mechanics, release dates, or controls.
- **Moon Sweeper:** Casey identified the viral Steam/Roblox moon-cleaning games as the reference. [Moon Sweepers by DragDrop Games on Steam](https://store.steampowered.com/app/5335510/Moon_Sweepers/) describes collecting lunar dust and upgrading tools. [Sweep The Moon on Roblox](https://www.roblox.com/games/109576450376407/Sweep-The-Moon) identifies Moon Sweepers as its inspiration. The project copy describes a planned cleaning loop; it does not promise the original's 16-player multiplayer, vehicles, or automation.
- **Devil 2:** Casey confirmed this exact display title, a browser remake, and Trea Edwards as creator. A follow-up asking whether this meant Level Devil 2 returned “just Devil 2.” Search did not establish the original unambiguously. Copy therefore says browser remake in progress, without importing Level Devil's trap-platformer mechanics or claiming an official association.

All three use Coming soon, Web browser, and no launch URL, release date, controls, or changelog. Their covers are original illustrations, drawn as SVG in `art/covers/` and rendered to WebP with `npm run render:covers`. They are labeled concept artwork and are not gameplay screenshots. Existing route slugs are retained so previously shared URLs still work.
